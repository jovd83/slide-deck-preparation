# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-12

### Added
- **Strategy Scorecard**: 0-10 calibration for narrative and delivery elements.
- **Refinement Loop**: Formalized "Judge & Refine" workflow for surgical deck improvements.
- **Visual Motif Schema**: Standardized global and slide-level visual motifs for downstream agents.
- **TED Anti-Patterns**: Integrated presentation guardrails into the instruction set.
- **High-Fidelity Sandboxes**: 5x master reference decks with full metadata and citations.
- **Automated CI/CD**: High-fidelity validator script and GitHub Actions integration.

### Added
- Initial release of `slide-deck-preparation`.
- Structured workflow for converting raw content into slide outlines.
- References for slide archetypes and output templates.
- MIT License and GitHub Actions validation.
- Standard AgentSkills badges and telemetry support.
